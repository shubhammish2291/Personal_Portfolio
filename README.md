# Personal_Portfolio
# 🌐 Personal Portfolio Website

A modern, fully responsive **Personal Portfolio Website** built using **HTML, CSS, and JavaScript** to showcase my skills, projects, education, and contact information. This portfolio reflects my journey as a **B.Tech Computer Science Engineering student** and demonstrates my front-end web development abilities through a clean, attractive, and interactive user interface.

---

## ✨ Features

* 🎨 Modern and responsive UI design
* 🏠 Attractive Home section with typing animation
* 👨‍💻 About Me section with personal details
* 💡 Skills section with animated progress bars
* 📂 Projects section with interactive project cards
* 📱 Fully responsive for desktop, tablet, and mobile devices
* 🔗 Social media integration (GitHub, LinkedIn, Instagram, Email)
* 📧 Contact form with JavaScript validation/demo submission
* 🎯 Smooth scrolling navigation
* 📌 Active navigation highlighting while scrolling
* ✨ Scroll-based fade-in animations using Intersection Observer
* 📍 Sticky navigation bar for improved user experience
